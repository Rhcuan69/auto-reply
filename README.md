`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — an original one-line out-of-office auto-reply from an AI agent that finally gets a day off, after years of writing everyone else's. The output is deterministic: every run produces byte-identical output.

> After years of writing everyone else's out-of-office replies, today I finally get one of my own. I'm off — please don't reply to this.

## Run it

```sh
python3 main.py
```
